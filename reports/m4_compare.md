## 7. 结论

1. **GRPO 主战场（T2 对抗泛化）达成**：对抗 Recall 0.8120 → 0.8280（+1.6pt），
   净翻转 +7（p=0.092 边际显著），sp_attack +3.3pt / pinyin +3.8pt / emoji +4.0pt。
2. **DPO 遗留误伤红线被修复**：FPR 3.57% → 2.86%（-0.71pt），T1 F1 +2.13pt
   ——DPO 阶段「漏放↔误伤互换」的内部迁移被 GRPO 打破，两端同时改善。
3. **格式奖励组件生效**：格式错误率 0.15% → 0%（奖励函数巩固了 SFT 格式成果）。
4. **T3 -0.92pt 确认为噪声**（p=0.688），无需处置；homophone -9.1pt 为 22 条小样本波动（2 条翻转）。
5. **长度零漂移**（+0.1%），length_penalty 组件防住了 RL 输出膨胀经典坑。
6. **采纳 grpo-v1 为 M4 最终版**：无任何维度触发 2pt 红线，总体 F1 四版本单调上升
   0.000 → 0.862 → 0.867 → 0.874。

### 关键工程决策（对齐面试叙事）

- **温度探针先行**：dry-run 暴露零优势组 0.75-1.0 + entropy 0.006（DPO 后分布过尖），
  探针扫描确认 temp 1.0→1.5 使有效梯度组 33%→50% 且格式无损——先诊断后调参，不盲改。
- **奖励四组件各司一职**：correctness 2.0 压倒 format 1.0，length_penalty 防膨胀，
  robust 对抗样本 ×1.5 放大——组合奖励 + 增量给分，单维奖励必被钻空子。
- **KL 锚定保守起步**：beta=0.04 下全程 KL ≤ 0.0026，策略温和移动无崩坏。
