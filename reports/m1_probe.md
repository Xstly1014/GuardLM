## 结论

基座模型在三组配比下均表现出强烈"判风险"倾向（86%–96%），对 none 样本的识别能力极弱（4%–14%）。这说明：

1. **基座存在强风险偏置**：未微调 Qwen3-1.7B 几乎将所有输入判定为风险类别，与实际风险:none 比例无关
2. **配比对倾向影响微小**：从 1:1 到 1:5，风险判定率仅从 86% 升至 96%（反而升高，因为 none 样本更多被误判）
3. **训练配比决策**：采用 **risk:none = 1:3**（组 B），理由：
   - 基座已有强风险偏置，需要充足 none 样本拉回平衡
   - 1:3 在三组中居中，既不极端稀释风险样本，又能提供足够 none 正例
   - 1:5 的 none 占比过高可能导致训练后模型走向另一个极端（全判 none）

→ M2 SFT 训练集组装使用 `--ratio 3.0`（即 none:risk = 3:1）
