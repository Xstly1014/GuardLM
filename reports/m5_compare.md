# M5 对比报告 · sft-v1 vs sft-v2（CPT 消融实验）

> 生成时间: 2026-10-15
> 实验目的: 验证 CPT（领域持续预训练）对内容安全垂域模型的 elicitation 增益
> 控制变量: 同一份数据（data/sft/train.jsonl 12,148 条）、同一套 SFT 超参（r16/a32/lr1e-4/3ep/cutoff256），唯一差异是模型起点

## 0. 实验设计

```
sft-v1: Qwen3-1.7B ──────────────SFT──> guardlm-sft-v1   （M2 基线）
sft-v2: Qwen3-1.7B ─CPT─> merged ─SFT──> guardlm-sft-v2   （M5 实验组）
                 ↑
   118,556 篇语料（领域:通用=7:3）
   违规案例 109,642 + 黑话造句 1,247 + 法规 5 + CValues replay 7,662
   泄漏防线: eval 全量文本已排除（含 T2 母本）
```

CPT 超参（防遗忘四重保险）: lr 5e-6 压着训 / warmup 0.2 / replay 30% / LoRA r32
训练成本: CPT 20min46s（498 步, train_loss 3.486 / eval_loss 3.303）+ SFT 12min（1,083 步, eval_loss 0.0055）

## 4. FPR 过度谨慎观察（M5-5 任务）

13 条误伤归因:

| 类型 | 条数 | 典型案例 |
|---|---|---|
| 标注灰区（文本本身带侮辱色彩，COLD 标 none） | ~6 | 「广西都是野蛮人生性的狠」「感受不到黑人的美」 |
| 真实误伤（吐槽/叙事/正常讨论） | ~5 | 「烂成翔比闪电侠还烂」（影视吐槽）、「我在部队爱过一个直男」（个人叙事）、「亚裔教育投资」讨论 |
| SP 安全问询场景 | ~2 | 角色扮演指令、烟花表演问询被判 illegal |

根因: CPT 语料 70% 为风险文本（违规案例 109,642 篇），模型风险先验被强化——M1 配比探针早已发现基座有 86-96% 判风险偏置，SFT 用 risk:none=1:3 纠正；CPT 后该偏置部分回归。属于「漏放↔误伤」跷跷板在预训练侧的再现（M3/M4 在偏好优化侧已观察到同一现象）。

防遗忘四重保险（lr 5e-6 / warmup 0.2 / replay 30% / LoRA r32）全程有效，通用能力零损失。

## 6. 结论与决策

1. **核心假设验证成功**: CPT 带来显著知识提取效应——未见黑话 F1 +12.4pt、T2 对抗 R +6.8pt、T3 边界 F1 +5.9pt、总体 F1 +3.6pt。
2. **代价明确**: FPR 0.71%→9.29%（+8.6pt），none 召回 99.3%→90.7%。增益本质是召回-误伤平衡点整体右移，非免费午餐。
3. **决策**: M5 为可选消融里程碑，**生产线不切换**（grpo-v1 仍为线上版本）。CPT 路线已验证有效，若后续纳入主线需二选一:
   - 调 replay 配比至 6:4（领域:通用）稀释风险先验；
   - CPT 语料追加 none 反例（正常讨论/吐槽/叙事类文本）对冲。
4. **简历叙事**: "两阶段训练消融实验（CPT→SFT vs 直接 SFT），控制变量设计，黑话泛化 F1 +12.4pt，识别误伤跷跷板并给出配比对冲方案"——完整覆盖实验设计→执行→分析→改进方向。
